# KeyLink

**Русский** | [English](README.en.md)

KeyLink (пакет `luci-app-keylink`) — веб-интерфейс LuCI для [Xray-core](https://github.com/XTLS/Xray-core) на OpenWrt: серверы по ссылкам и подпискам, маршрутизация по доменам и IP, балансировка, защищённый DNS и встроенный обход DPI без VPN.

Все настройки хранятся в UCI (`/etc/config/keylink`). Интерфейс редактирует только UCI, а конфигурацию Xray при каждом запуске собирает из неё отдельный скрипт. Поэтому руками JSON Xray трогать не нужно, а логику генерации можно отлаживать прямо в консоли.

## Возможности

- **Серверы по ссылкам**: `vless://` (в том числе REALITY и Vision), `vmess://`, `trojan://`, `ss://` (SIP002 и старый формат), `hysteria2://` / `hy2://`. Транспорты TCP, WebSocket, gRPC, XHTTP, HTTPUpgrade. Можно вставить сразу пачку ссылок.
- **Hysteria2** с обфускацией Salamander, прыжками по портам и ограничением скорости. Формат прыжков подбирается под установленную версию Xray автоматически.
- **Подписки**: загрузка по расписанию, при необходимости через уже работающий прокси. Фильтры по названию серверов, показ израсходованного трафика и срока действия. Теги серверов сохраняются между обновлениями, поэтому правила не ломаются.
- **Проверка задержки** любого сервера или всех сразу, через реальное соединение.
- **Балансировщики**: наименьшая задержка, наименьшая нагрузка, случайный или по очереди. Можно включить в балансировщик все серверы подписки целиком и задать запасной маршрут.
- **Маршрутизация**: правила по доменам (`geosite:`, `domain:`, `full:`, `keyword:`, `regexp:`), IP (`geoip:`, CIDR), устройствам LAN, портам, сети и протоколу. Порядок меняется перетаскиванием.
- **Прозрачный прокси** для всей локальной сети (TPROXY, IPv4), а также порты SOCKS5 и HTTP.
- **DNS**: российские домены резолвятся локальным DNS, остальные — через DoH в туннеле. dnsmasq перенаправляется автоматически и восстанавливается при остановке.
- **Обход DPI без VPN**:
  - [ByeDPI](https://github.com/hufrea/byedpi): рассинхронизирующий SOCKS-прокси, 21 пресет;
  - [Zapret 2](https://github.com/bol-van/zapret2) (nfqws2): рассинхронизация на уровне пакетов, 11 пресетов, обход для голоса Discord;
  - тестер стратегий по нескольким сайтам для обоих движков.

## Требования

- OpenWrt 22.03 или новее: нужны fw4/nftables и ucode.
- Xray-core. Для Hysteria2 нужна версия 26.3.27 или новее (проверить: `xray version`); если в репозитории старее, установщик поставит официальную сборку.
- Около 30–40 МБ свободного места, в основном под Xray и geo-файлы.

Установщик ставит зависимости: `xray-core`, `ucode`, `ucode-mod-uci`, `ucode-mod-fs`, `kmod-nft-tproxy`, `curl`. Базы `v2ray-geosite` (~2 МБ) и `v2ray-geoip` (~22 МБ) ставятся, если хватает места: без них работают все правила, кроме правил с `geosite:`/`geoip:`.

Для обхода DPI нужны дополнительные пакеты, они ставятся отдельно:

| Движок | Что нужно |
|---|---|
| ByeDPI | пакет byedpi (бинарник `ciadpi`) |
| Zapret 2 | пакет zapret2 (`nfqws2` и Lua-скрипты), `kmod-nft-queue` |

Готовые сборки для OpenWrt есть, например, у [1andrevich/ByeDPI-OpenWrt](https://github.com/1andrevich/ByeDPI-OpenWrt) и [1andrevich/zapret2-openwrt](https://github.com/1andrevich/zapret2-openwrt).

## Установка

### Установщиком

Скопируйте архив на роутер и запустите установщик:

```sh
scp luci-app-keylink.tar.gz root@192.168.1.1:/tmp/
ssh root@192.168.1.1
cd /tmp && tar xzf luci-app-keylink.tar.gz && sh luci-app-keylink/install.sh --lang ru
```

Или одной строкой из последнего релиза:

```sh
wget -qO- https://github.com/remyweinstein/luci-app-keylink/releases/latest/download/install.sh | sh -s -- --lang ru
```

Установщик из релиза сам знает, откуда скачать архив. Для другого источника укажите его явно: `KEYLINK_URL=https://…/luci-app-keylink.tar.gz`.

### Пакетом OpenWrt

В релизе также есть готовые пакеты для штатного менеджера OpenWrt: `.ipk` собран для OpenWrt 23.05 (opkg), `.apk` — для OpenWrt 25.12 (apk). Используйте пакет для своей системы:

```sh
opkg update
opkg install ./luci-app-keylink.ipk
# или для apk; пакет релиза не подписан:
apk add --allow-untrusted ./luci-app-keylink.apk
```

Установка пакетом ставит обязательные зависимости и регистрирует службу KeyLink. Необязательные базы geoip/geosite и движки DPI пакет не устанавливает. Модуль `kmod-nft-tproxy` нужно установить из репозитория именно вашей модели роутера и версии OpenWrt, если вы включаете прозрачный прокси для LAN. Для сборок других версий OpenWrt используйте установщик выше.

### Выпуск релиза

Релиз автоматически собирается GitHub Actions при отправке тега с префиксом `v`. Например, чтобы выпустить `v1.0.0`:

```sh
git tag -a v1.0.0 -m "Release v1.0.0"
git push origin v1.0.0
```

Workflow создаст GitHub Release с архивом `luci-app-keylink.tar.gz`, готовым `install.sh` и пакетами `luci-app-keylink.ipk` / `luci-app-keylink.apk`.

Установщик:

1. проверяет систему и свободное место;
2. ставит зависимости через apk или opkg;
3. если Xray в репозитории старше 26.3.27, предлагает поставить официальную сборку из [XTLS/Xray-core](https://github.com/XTLS/Xray-core/releases) (с проверкой контрольной суммы), чтобы работала Hysteria2;
4. копирует файлы, не трогая существующие настройки;
5. по желанию ставит ByeDPI и Zapret 2: сначала пробует официальный репозиторий, затем сборки [1andrevich](https://github.com/1andrevich);
6. отключает собственные службы движков и находит пути к файлам zapret2.

Ключи:

| Ключ | Действие |
|---|---|
| `-y` | без вопросов; движки DPI ставятся только с `--with-…` |
| `--with-byedpi`, `--with-zapret` | установить движок DPI |
| `--no-byedpi`, `--no-zapret` | не устанавливать и не спрашивать |
| `--xray-update` | поставить последний официальный Xray, даже если версия из репозитория подходит; так же можно обновить Xray позже |
| `--no-xray-update` | оставить Xray из репозитория и не спрашивать |
| `--with-ru` | установить русский перевод KeyLink и общих элементов LuCI |
| `--lang en\|ru` | язык сообщений установщика, по умолчанию английский |
| `--uninstall` | удалить keylink, настройки останутся |
| `--purge` | удалить вместе с настройками |

Если GitHub недоступен, укажите зеркало: `GH_MIRROR=https://ваше.зеркало sh install.sh --lang ru`.

### Обновление

Обновляться можно из LuCI: «Общие» → «Версия» → «Проверить обновления». Кнопка показывает установленную и последнюю версии; установленный пакет обновляется через apk/opkg, а установка через скрипт — запуском установщика последнего релиза (`install.sh -y --no-xray-update`). Настройки сохраняются, в конце KeyLink перезапускается, ход обновления виден в окне. Из командной строки пакет обновляется установкой нового `.apk`/`.ipk`, а скриптовая установка — той же командой, что и при установке.

При удалении служба сначала останавливается: настройки dnsmasq возвращаются, правила nftables и задание cron удаляются. Пакеты xray-core, byedpi и zapret2 остаются, их можно удалить отдельно.

### Сборка пакета

Положите каталог `luci-app-keylink` в `feeds/luci/applications/` в OpenWrt buildroot или SDK, затем:

```sh
./scripts/feeds update -a && ./scripts/feeds install -a
make package/luci-app-keylink/compile V=s
```

Готовый пакет появится в `bin/packages/*/luci/`.

### Вручную (для разработки)

```sh
# на роутере: зависимости
apk add xray-core ucode ucode-mod-uci ucode-mod-fs kmod-nft-tproxy v2ray-geoip v2ray-geosite curl
# или: opkg update && opkg install …

# с компьютера: файлы пакета
scp -r root/* root@192.168.1.1:/
scp -r htdocs/* root@192.168.1.1:/www/

# на роутере
chmod +x /etc/init.d/keylink /usr/libexec/rpcd/keylink /usr/libexec/keylink/*.sh
rm -rf /tmp/luci-*; /etc/init.d/rpcd restart
/etc/init.d/keylink enable
/etc/init.d/keylink restart
```

После этого в LuCI появится раздел **Службы → KeyLink**.

`restart` нужен и при первой установке: он регистрирует в procd обработчик применения настроек LuCI. Пока «Включить» выключено, Xray и движки DPI не запускаются.

> Если у вас уже был установлен пакет byedpi или zapret2 со своей службой, отключите её (`/etc/init.d/byedpi disable && /etc/init.d/byedpi stop`, то же для `zapret2`). Запуском движков управляет keylink. Служба ByeDPI по умолчанию занимает порт 1080, совпадающий с SOCKS-портом Xray, а служба zapret2 ставит свои правила nftables.

## Быстрый старт

1. **Серверы**: вставьте ссылки в поле «Добавить по ссылкам» или заведите подписку на вкладке «Подписки».
2. **Общие**: включите службу, выберите основной маршрут (сервер или балансировщик) и, если нужно, прозрачный прокси для LAN.
3. **Маршрутизация**: проверьте правила. По умолчанию российские сайты и торренты идут напрямую.
4. Нажмите **«Сохранить и применить»**.

Если VPN-сервера нет, а нужно только снять замедление YouTube и Discord, откройте вкладку **«Обход DPI»**, подберите стратегию тестером и нажмите кнопку быстрого действия «YouTube и Discord через …».

## Язык интерфейса

Базовый язык KeyLink — английский. Русский перевод устанавливается по желанию:

```sh
wget -qO- https://github.com/remyweinstein/luci-app-keylink/releases/latest/download/install.sh | sh -s -- --lang ru --with-ru
```

Для распакованного релиза: `sh install.sh --lang ru --with-ru`. При последующих обновлениях установщик обновляет уже установленный перевод и без этого ключа.

Если в LuCI уже выбран русский, установщик добавляет перевод автоматически, в том числе при обновлении старой версии KeyLink. При выборе языка `auto` (или отсутствии настройки) перевод добавляется, если установлен русский каталог базового интерфейса LuCI. Явно выбранный английский или другой язык сохраняется.

Затем выберите **Русский** в **System → System → Language and Style → Language** и нажмите **Save & Apply**. Чтобы вернуться к английскому, выберите **English**. Это стандартный выбор языка всего LuCI; установщик не меняет его автоматически.

При сборке через OpenWrt SDK перевод из `po/ru/keylink.po` собирается в отдельный пакет `luci-i18n-keylink-ru`: включите русский язык в настройках переводов LuCI при сборке. Установите полученный `.ipk`/`.apk` вместе с `luci-i18n-base-ru` для перевода общих кнопок LuCI. Пакет KeyLink и его перевод нужно брать из одной сборки; в официальном репозитории OpenWrt этого пакета может не быть.

При установке из исходников сначала выполните `PO2LMO=/путь/к/po2lmo sh scripts/build-i18n.sh`, затем `sh install.sh --lang ru --with-ru`. Компилятор `po2lmo` входит в инструменты LuCI SDK; в архиве релиза перевод уже собран. При ручном копировании файлов поместите `i18n/keylink.ru.lmo` в `/usr/lib/lua/luci/i18n/` и установите `luci-i18n-base-ru`.

Переключение языка не переименовывает сохранённые серверы, подписки и пользовательские правила, в том числе русские названия из старых конфигураций.

## Добавление своих пресетов

Пресеты лежат в `/usr/share/keylink/dpi_presets.json`. Новая запись сразу появляется и в списке стратегий, и в тестере:

```json
{ "id": "my_preset", "name": "Мой пресет", "args": "--disorder 1 --tlsrec 3+s" }
```

Правила для аргументов:

- **ByeDPI**: без `-i` и `-p`, их задаёт служба.
- **Zapret 2**: без `--qnum` и `--lua-init`, их добавляет служба. Профили разделяются `--new`. Вместо `${FAKE}` подставляется каталог с фейковыми пакетами zapret2.

Значения внутри аргументов не должны содержать пробелов: аргументы делятся по пробелам без учёта кавычек. Проверить пресет Zapret 2 перед добавлением можно командой `nfqws2 --qnum=200 <аргументы> --dry-run`.

## Решение проблем

**Установщик пишет, что не установлены v2ray-geoip или v2ray-geosite.** Почти всегда не хватает места: полная база geoip занимает около 22 МБ. Это не мешает работе. Без geoip частные сети задаются явными подсетями, а правила с `geoip:` пропускаются. Без geosite так же пропускаются правила с `geosite:`. Какие условия пропущены, видно в `logread -e keylink`. Для правил по доменам можно использовать `domain:` и `full:` — им базы не нужны.

**Xray не запускается.** Выполните `ucode /usr/share/keylink/gen_config.uc > /tmp/c.json && xray run -test -c /tmp/c.json`: Xray укажет, какой сервер или параметр ему не нравится.

**После включения DNS перестали открываться сайты.** Если Xray не работает, имена в сети не резолвятся. Выключите DNS на вкладке «DNS» или выполните `/etc/init.d/keylink stop`: настройки dnsmasq вернутся. Затем проверьте, что основной маршрут рабочий.

**Подписка отвечает «нет поддерживаемых серверов».** Попробуйте другой User-Agent. Многие панели отдают список ссылок только знакомым клиентам, а некоторым клиентам вместо ссылок присылают JSON-конфиги, которые пока не разбираются.

**Hysteria2 не подключается.** Проверьте `xray version`: нужна 26.3.27 или новее. В OpenWrt 24.10 в репозитории версия 25.1.30, и серверы Hysteria2 на ней пропускаются (это видно в `logread -e keylink`), а остальные работают. Установщик предлагает заменить её официальной сборкой; если вы отказались, выполните `sh install.sh --lang ru --xray-update`. Для прыжков по портам сервер должен перенаправлять весь диапазон на свой порт.

**Zapret 2 не действует.**
- Проверьте, что установлен `kmod-nft-queue` и существует таблица `nft list table inet keylink_zapret`.
- Отключите собственную службу zapret2.
- При включённом аппаратном ускорении (flow offloading) часть пакетов обходит nftables, попробуйте его отключить.

**Тестер показывает, что всё открывается и без обхода.** Сайты сейчас не блокируются, или замедление проявляется позже, чем загрузка главной страницы. Добавьте в список адрес, с которого скачивается много данных.

## Ограничения

- Прозрачный прокси работает только для IPv4. По умолчанию DNS отдаёт только IPv4-адреса, чтобы трафик не уходил мимо прокси по IPv6.
- Проверка задержки и обновление подписки работают с применёнными настройками. Новый сервер или подписку сначала сохраните и примените.
- Подписки в форматах JSON Xray/sing-box и YAML Clash не поддерживаются, только списки ссылок (обычные или в base64).
- Серверы из подписки перезаписываются при каждом обновлении, ручные правки в них не сохраняются.
